# 🛒 Smart Store App

A modern, responsive, and beautifully structured E-Commerce Store application built with **Flutter & Dart**. 

## ✨ Key Features
- **Clean Architecture:** Organized code structure with separate files for models and UI screens.
- **Interactive Grid UI:** Displays products smoothly with dynamic response across different screen sizes.
- **Instant Actions:** Interactive notifications using Flutter SnackBar when adding items to the cart.

## 🛠️ Tech Stack
- Flutter (Framework)
- Dart (Language)

## 📌 Future Roadmap
- Integrate with **Firebase Authentication** for user login.
- Connect to a real backend database for live product updates.
- Implement advanced State Management using **Bloc/Provider**.
